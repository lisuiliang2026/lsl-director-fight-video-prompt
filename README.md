# 导演打斗模块 · lsl-director-fight-video-prompt

一个 Claude skill：把剧本里的一段打斗戏，写成一条可以整段粘贴进视频模型生成的**全量提示词**。

- **版本**：v0.3（2026-11-13），测试版。效果还没有通过生成验证。
- **目标模型**：即梦 Seedance 2.5，单段 15 秒以内。只出文本，不生成图片和视频。
- **和 director-video-prompt**：独立运行，行格式和它的投喂版一致，测到认可后再并入。

skill 本体是 [`lsl-director-fight-video-prompt/SKILL.md`](lsl-director-fight-video-prompt/SKILL.md)，下面的章节号都指它。

## 交付什么

一段戏交三样：给人看的工作稿（类型判定、打斗档案、回合表）、给模型的全量提示词、每条可删的设计说明。

全量提示词是固定的两行加十块：上传顺序、配乐声明；影像规格与质感、光影与色彩、场景环境、人物设定、特效设定、环境反应设定、声音设计、运镜设计、完整动作流程、保持。里面只有画面和声音，没有表格和说明。模板和每块必写的内容见第十三节，完整示例见 [`examples/`](examples/示例_全量提示词_祝融对共工_15秒.txt)。

## 方法

| 规则 | 一句话 | 章节 |
|---|---|---|
| 类型和底座 | 按剧本描写判真人、武侠、玄幻、奇幻；没写发光就不发光 | 三 |
| 骨架 | 段 → 回合 → 接触 → 交手；一次接触 3–6 下，招式各不同 | 六 |
| 特效五段 | 起手、成形、传导、命中、残留 | 3.3 |
| 力 | 每次命中写接触点、身体、环境、画面响应，至少三样 | 七 |
| 环境反应 | 近先远后、方向一致、坏了就留着、由轻到重 | 八 |
| 镜头 | 15 秒 11–16 个视角；每击换角度；高潮连切 | 九 |
| 机位摆得出来 | 机位、焦段和“画面里看得到谁”要对得上 | 9.10 |
| 爽点 | 压了再放 | 十 |
| 收束 | 拉远以后能量不散，收幅留给下一段接 | 十二 |

交稿前有 23 条自检（第十六节），生成后有 34 行的现象对照表（第十七节）。

提示词写完后可以另出一个简模界面，把机位和走位摆出来查问题。这一步默认不做，要了才做，见第十九节。

## 安装和使用

把 `lsl-director-fight-video-prompt` 这个文件夹（仓库里面那一层）压成 zip，在 Claude 的 Customize → Skills 里上传；Claude Code 放到 `~/.claude/skills/` 下。

用的时候把这段戏的材料给它：谁对谁、谁赢、每人能用什么、台词原文、打完的代价、时长和画幅、剧本里相关的描写。缺的它会提案并标出来，只有“谁赢”和“台词归属”不明才会问。
